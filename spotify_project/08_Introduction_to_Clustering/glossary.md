# Module 08 — Glossary

| Term | Simple Meaning | Spotify Example |
|---|---|---|
| Clustering | Group similar records | Group similar listeners |
| Unsupervised Learning | Learning without target labels | Discover personas |
| Similarity | How alike two users are | Similar listening patterns |
| Distance | Numeric difference | User-to-user distance |
| Euclidean Distance | Straight-line distance | Distance in scaled feature space |
| Feature Space | Coordinate system of features | Listening and engagement axes |
| Cluster | Group of similar users | Cluster 2 |
| Hard Clustering | One cluster per user | K-Means |
| Soft Clustering | Membership probabilities | GMM |
| Centroid | Average cluster position | Average Power Streamer |
| Cluster Label | Technical group ID | 0, 1, 2, 3 |
| Persona | Business identity | Habitual Loyalists |
| K | Number of clusters | K = 4 |
| Inertia | Within-cluster squared distance | K-Means compactness |
| Silhouette Score | Cohesion and separation | Compare candidate K |
| Cluster Balance | User distribution across groups | Cluster percentages |
| Stability | Consistency across runs | Similar profiles after retraining |
| Boundary User | User near multiple clusters | Mixed listening behavior |
| Membership Probability | Likelihood of each cluster | 70% Cluster 1 |
| Actionability | Business usefulness | Targeted Premium offer |
