| Term | Simple Meaning | Spotify Example |
|---|---|---|
| Data Visualization | Graphical representation | Persona chart |
| Exploratory Chart | Used to investigate | Correlation heatmap |
| Explanatory Chart | Used to communicate | Premium-opportunity chart |
| Histogram | Numerical distribution | Listening minutes |
| Bin | Numerical interval | 20-minute range |
| Box Plot | Quartile summary | Skip rate by persona |
| Bar Chart | Category comparison | Persona sizes |
| Scatter Plot | Two-variable relationship | Sessions vs listening |
| Heatmap | Matrix visualization | Feature correlation |
| Pair Plot | Pairwise feature matrix | Behavior relationships |
| Cluster Chart | Visualized cluster labels | PCA cluster chart |
| PCA | Linear projection | Two cluster dimensions |
| Radar Chart | Multi-dimensional profile | Persona profile |
| Persona Comparison | Compare segment metrics | Engagement levels |
| Dashboard | KPI monitoring view | Persona business dashboard |
| KPI | Key performance indicator | Premium conversion |
| Filter | Data-selection control | Persona or device |
| Overplotting | Points hide each other | Large scatter plot |
| Annotation | Highlighted explanation | Key insight label |
| Data Story | Evidence to action narrative | Premium hypothesis |
| Guardrail Metric | Protects against harm | Churn |
| Visual Clutter | Unnecessary chart elements | Excessive labels |
| Projection | Reduced-dimensional view | PCA |
