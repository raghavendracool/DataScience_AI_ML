# Module 14 — Quick Cheat Sheet

## Core Relationship

```text
Cluster = Technical output
Segment = Business interpretation
Persona = Human-readable representation
```

## Persona Creation

```text
Profile cluster
→ Identify dominant behavior
→ Write neutral summary
→ Define segment
→ Create persona name
→ Add needs, risks and opportunities
→ Define actions
→ Validate and test
```

## Persona Components

```text
Name
One-line summary
Size
Characteristics
Needs
Risks
Opportunities
Actions
Evidence
Limitations
```

## Example Personas

```text
Casual Snackers
Exploratory Samplers
Habitual Loyalists
Power Streamers
```

## Naming Rule

```text
Describe behavior.
Avoid judgment and stereotypes.
```
