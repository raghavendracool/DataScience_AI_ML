# Project Limitations

1. The included final values are illustrative.
2. Clustering has no true labels for direct accuracy.
3. The project may use a static time window.
4. User behavior can change.
5. Personas simplify variation within a cluster.
6. Demographic association does not prove causation.
7. Growth recommendations are hypotheses.
8. CLV examples are simplified.
9. Production drift monitoring is not yet implemented.
10. Fairness and privacy review require production-specific policies.
