# Module 12 — Glossary

| Term | Simple Meaning | Spotify Example |
|---|---|---|
| Cluster Evaluation | Judge clustering quality | Select final persona model |
| Internal Metric | Uses data and labels | Silhouette |
| External Metric | Compares label sets | ARI stability |
| Silhouette Score | Cohesion and separation | Compare K values |
| Davies-Bouldin | Cluster similarity | Lower is better |
| Calinski-Harabasz | Between/within dispersion | Higher is better |
| Inertia | K-Means squared distance | Elbow Method |
| Log-Likelihood | GMM probability fit | Higher is better |
| AIC | Fit plus penalty | Lower is better |
| BIC | Stronger fit penalty | Lower is better |
| Cluster Size | Users in a cluster | 25,000 users |
| Cluster Balance | Relative size evenness | No 90% cluster |
| Stability | Similarity across reruns | Same profiles |
| ARI | Adjusted Rand Index | Compare seeds |
| Interpretability | Easy to explain | Clear Power Streamer |
| Actionability | Supports a distinct action | Premium campaign |
| Shortlist | Final candidates | Top three models |
| Scorecard | Multi-factor comparison | Technical + business |
| Comparability | Valid metric comparison | Same transformed space |
