# Spotify User Behavior Segmentation Project

> A structured learning project covering Artificial Intelligence, Machine Learning, Unsupervised Learning, clustering, customer segmentation, personas, and business recommendations using Spotify user behaviour data.

---

## Project Objective

The objective is to identify hidden behavioural groups among Spotify users and translate technical clusters into meaningful business personas and actions.

```text
Spotify User Data
        ↓
Data Cleaning
        ↓
Exploratory Data Analysis
        ↓
Feature Engineering
        ↓
Scaling and Transformation
        ↓
K-Means and GMM
        ↓
Cluster Evaluation
        ↓
Cluster Profiling
        ↓
Customer Segmentation
        ↓
Persona Creation
        ↓
Business Recommendations
```

## Expected Learning Outcome

Students will be able to:

- Explain AI, ML, and Deep Learning
- Differentiate supervised and unsupervised learning
- Clean and analyse Spotify user data
- Select and engineer behavioural features
- Apply scaling and transformation
- Train K-Means and GMM models
- Automate and compare experiments
- Evaluate clustering quality
- Profile clusters
- Create customer segments and personas
- Translate model output into business recommendations
