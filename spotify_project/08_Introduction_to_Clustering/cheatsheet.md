# Module 08 — Quick Cheat Sheet

## Definition

```text
Clustering
= Grouping similar observations without predefined labels
```

## Similarity

```text
Small distance → More similar
Large distance → Less similar
```

## Euclidean Distance

```text
distance = √Σ(feature difference²)
```

## Types

```text
Hard clustering
→ One cluster per user
→ K-Means

Soft clustering
→ Probability for each cluster
→ GMM
```

## Centroid

```text
Average position of one cluster
```

## Cluster Labels

```text
0, 1, 2, 3
```

Labels have no ranking.

## Choosing K

```text
Elbow Method
Silhouette Score
Cluster balance
Stability
Business interpretability
```

## Business Flow

```text
Behavior
→ Scaling
→ Clustering
→ Profiles
→ Personas
→ Actions
```
