# Spotify EDA Checklist

## Preparation

- [ ] Clean datasets loaded
- [ ] Shapes validated
- [ ] `user_id` excluded from numerical analysis
- [ ] Behavior and demo datasets joined safely

## Descriptive Statistics

- [ ] Mean reviewed
- [ ] Median reviewed
- [ ] Mode reviewed where meaningful
- [ ] Standard deviation reviewed
- [ ] Minimum and maximum reviewed
- [ ] Percentiles reviewed

## Distribution Analysis

- [ ] Histograms created
- [ ] Box plots created
- [ ] Skewness calculated
- [ ] Long tails documented
- [ ] Multiple peaks investigated
- [ ] Extreme values reviewed

## Univariate Analysis

- [ ] Every key numerical feature summarized
- [ ] Category frequency tables created
- [ ] Low-variance features identified

## Bivariate Analysis

- [ ] Numerical vs numerical analyzed
- [ ] Categorical vs numerical analyzed
- [ ] Categorical vs categorical analyzed

## Multivariate Analysis

- [ ] Engagement dimensions analyzed together
- [ ] Friction variables compared with engagement
- [ ] Demographic profiling tables created

## Correlation

- [ ] Pearson matrix calculated
- [ ] Spearman matrix calculated
- [ ] Strong positive pairs documented
- [ ] Strong negative pairs documented
- [ ] Redundant features reviewed
- [ ] Correlation not interpreted as causation

## Business Insights

- [ ] Observation documented
- [ ] Supporting evidence recorded
- [ ] Behavioral interpretation written
- [ ] Business impact explained
- [ ] Next analysis recommended
- [ ] Alternative explanations considered
