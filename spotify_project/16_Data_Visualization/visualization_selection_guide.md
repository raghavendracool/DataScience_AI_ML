# Visualization Selection Guide

| Question Type | Recommended Chart | Avoid When |
|---|---|---|
| Distribution of one numerical feature | Histogram | Exact values are the main goal |
| Spread and outliers across groups | Box plot | Audience does not understand quartiles without explanation |
| Category comparison | Bar chart | Too many categories |
| Relationship between two numerical features | Scatter plot | One or both variables are categorical |
| Correlation matrix | Heatmap | Too many unreadable features |
| Pairwise exploration | Pair plot | Large feature count or large unsampled dataset |
| Cluster separation | PCA cluster chart | Used as the only evaluation evidence |
| Multi-dimensional persona | Radar chart | Too many personas or dimensions |
| Ongoing KPI monitoring | Dashboard | No clear owner or action |
| Action prioritization | Impact-effort scatter | Impact and effort scores are not defined |

## Decision Rule

Choose the chart that makes the required comparison easiest to see.

Do not choose a chart because it looks impressive.
