# Executive Project Summary

## Project Title

Spotify User Segmentation and Persona-Based Growth Strategy

## Objective

Segment users according to behavior and create actionable personas.

## Data

- Behavioral usage data
- Demographic context
- User identifiers used only for joins and outputs

## Methods

- Data cleaning
- EDA
- Feature selection
- Feature engineering
- Scaling and transformations
- K-Means
- Gaussian Mixture Models
- Experiment automation
- Multi-metric evaluation
- Stability testing
- Cluster profiling
- Persona creation

## Illustrative Final Selection

```text
Preprocessing: StandardScaler
Algorithm: K-Means
Clusters: 4
```

## Illustrative Personas

1. Casual Snackers
2. Exploratory Samplers
3. Habitual Loyalists
4. Power Streamers

## Business Value

- Personalized recommendations
- Retention actions
- Discovery strategy
- Loyalty strategy
- Premium conversion
- Advertisement optimization

## Limitations

- Final values are illustrative
- Clustering has no true labels
- Recommendations require causal testing
- Static profiles may drift

## Next Phase

Production pipeline, tracking, monitoring, controlled tests and retraining.
