# Module 03 — Glossary

| Term | Simple Meaning | Spotify Example |
|---|---|---|
| Dataset | Collection of records | Spotify user table |
| Row | One observation | One Spotify user |
| Column | One variable | `skip_rate` |
| Grain | Meaning of one row | One row per user |
| Schema | Dataset structure | 26 behavior columns |
| Identifier | Unique record reference | `user_id` |
| Primary Key | Unique, non-null identifier | `user_id` |
| Numerical Data | Data used in calculations | Listening minutes |
| Categorical Data | Data representing groups | Device type |
| Continuous Data | Measured decimal values | Skip rate |
| Discrete Data | Countable values | Days active |
| Feature | Model input | Sessions per day |
| Metadata | Data describing data | Data dictionary |
| Data Dictionary | Column documentation | Description and typical range |
| Relationship | Connection between datasets | Join on `user_id` |
| One-to-One | One record matches one record | Demo user to behavior user |
| Join | Combine datasets | Pandas `merge()` |
| Cardinality | Type of table relationship | One-to-one |
| Behavioral Data | What the user does | Listening and skips |
| Demographic Data | Who the user is | Age and country |
