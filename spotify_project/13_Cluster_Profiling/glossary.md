# Module 13 — Glossary

| Term | Simple Meaning | Spotify Example |
|---|---|---|
| Cluster Profiling | Describe cluster behavior | Profile Cluster 3 |
| Cluster Mean | Average within a cluster | 232 minutes |
| Cluster Median | Middle value | 210 minutes |
| Percentile | Distribution position | P25 and P75 |
| Absolute Comparison | Original units | 29 active days |
| Relative Comparison | Compared with average | 40% above average |
| Standardized Profile | Standard-deviation comparison | +1.2 |
| High Feature | Above-average characteristic | High listening |
| Low Feature | Below-average characteristic | Low skip rate |
| Behavioral Profile | What users do | Frequent listening |
| Demographic Profile | User context | Device and age |
| Cluster Summary | Short evidence-based explanation | Power-user summary |
| Cluster Name | Short identifier | Power Streamers |
| Persona | Business-friendly segment | Habitual Loyalists |
| Business Interpretation | Why a cluster matters | Premium potential |
| Actionability | Distinct action possible | Retention campaign |
| Boundary User | Mixed GMM membership | 51% vs 46% |
| Membership Confidence | Strongest GMM probability | 0.84 |
| Profile Stability | Consistency across runs | Same persona meaning |
| Persona Mapping | Cluster-to-name table | Cluster 3 → Power Streamers |
