# Module 06 — Glossary

| Term | Simple Meaning | Spotify Example |
|---|---|---|
| Feature | Model input | `skip_rate` |
| Raw Feature | Existing source column | `sessions_per_day` |
| Derived Feature | Newly calculated column | `friction_score` |
| Feature Selection | Choosing useful columns | Keep engagement features |
| Feature Engineering | Creating new columns | Create loyalty score |
| Identifier | Record key | `user_id` |
| Relevant Feature | Supports the objective | Listening minutes |
| Irrelevant Feature | Does not support objective | Row sequence |
| Redundancy | Overlapping information | Daily and weekly equivalents |
| Correlation | Relationship between features | Sessions and listening time |
| Low Variance | Little variation | Nearly same value for all users |
| Near Constant | One value dominates | 99% same category |
| Interaction Feature | Combined behavioral effect | Engagement minus friction |
| Ratio Feature | One measure divided by another | Active-day ratio |
| Composite Score | Combined feature score | Loyalty score |
| Data Leakage | Improper future information | Future conversion |
| Feature Set | Features used in one experiment | Core persona set |
| Model Feature | Used to create clusters | Skip rate |
| Profiling Feature | Used after clustering | Country |
| Scaling | Making magnitudes comparable | StandardScaler |
| Encoding | Converting category to numbers | One-hot device type |
| Feature Catalog | Feature documentation | Name, formula, meaning |
| Interpretability | Ease of explanation | Clear persona meaning |
