# Module 14 — Persona Creation Checklist

## Cluster Evidence

- [ ] Selected model documented
- [ ] Cluster size documented
- [ ] Mean profile reviewed
- [ ] Median profile reviewed
- [ ] High and low features reviewed
- [ ] Relative profile reviewed
- [ ] Demographics reviewed
- [ ] Stability reviewed
- [ ] GMM confidence reviewed when applicable

## Segment Definition

- [ ] Segment purpose is clear
- [ ] Segment definition is measurable
- [ ] Segment is distinct
- [ ] Segment is stable enough to use
- [ ] Segment has business relevance
- [ ] Segment supports a distinct action

## Persona Identity

- [ ] Persona name is neutral
- [ ] Persona name is behavior-based
- [ ] One-line summary is written
- [ ] Persona size is included
- [ ] Core characteristics are included
- [ ] Demographic context is included carefully

## Persona Strategy

- [ ] Primary needs documented
- [ ] Primary risks documented
- [ ] Opportunities documented
- [ ] Product actions documented
- [ ] Recommendation actions documented
- [ ] Retention actions documented
- [ ] Premium actions documented
- [ ] Advertising actions documented

## Validation

- [ ] Stakeholder review completed
- [ ] Fairness review completed
- [ ] Evidence table attached
- [ ] Business test designed
- [ ] Success metrics defined
- [ ] Persona version recorded
- [ ] Refresh schedule documented
