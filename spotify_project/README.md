# 🎵 Spotify User Behavior Segmentation Project

> A module-wise learning project for understanding **Artificial Intelligence, Machine Learning, Unsupervised Learning, Clustering, Customer Segmentation, Persona Creation, and Business Growth Strategy** through Spotify user behavior data.

---

## 📖 Project Overview

Spotify users do not all behave in the same way.

Some users:

- Listen for long hours
- Open Spotify many times per day
- Use the platform consistently
- Skip many songs
- Skip advertisements
- Follow many artists and playlists
- Discover new genres
- Repeat the same songs
- Use Spotify only occasionally

The objective of this project is to identify hidden behavioral patterns, group similar users, create meaningful segments and personas, and connect those findings to Spotify's business-growth strategies.

---

## 🎯 Main Business Questions

This project aims to answer:

- What types of Spotify users exist?
- Which users are highly engaged?
- Which users are casual listeners?
- Which users explore new content?
- Which users may be at risk of leaving?
- Which users have Premium-conversion potential?
- Which users are sensitive to advertisements?
- Which users show strong loyalty?
- How can Spotify target each group differently?
- How can segmentation improve engagement, retention, and revenue?

---

## 🤖 Machine Learning Problem

This is an **Unsupervised Learning** project.

The dataset does not contain predefined columns such as:

```text
user_persona
customer_segment
listener_type
```

Therefore, the algorithm must discover hidden groups based on similarities in user behavior.

```text
Spotify User Data
        ↓

        ↓
Clustering

```
