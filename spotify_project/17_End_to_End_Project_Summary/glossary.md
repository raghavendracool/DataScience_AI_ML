# Module 17 — Glossary

| Term | Meaning |
|---|---|
| End-to-End Project | Complete workflow from business problem to action |
| Technical Architecture | Data, processing, model and artifact design |
| Business Architecture | Segment, action and KPI design |
| Model Selection | Choosing the best-supported candidate |
| Final Cluster | Selected technical group |
| Final Persona | Business-friendly cluster representation |
| Experiment Automation | Programmatic testing of configurations |
| Stability | Consistency across reruns or samples |
| Business Interpretability | Ease of explaining and using clusters |
| Deployment Simplicity | Ease of operational implementation |
| Growth Recommendation | Testable action linked to persona evidence |
| Primary KPI | Main experiment outcome |
| Guardrail KPI | Metric protecting against harm |
| Project Limitation | Known uncertainty or constraint |
| Future Enhancement | Planned improvement |
| Productionization | Making the solution operational |
| Model Registry | Versioned model and metadata store |
| Drift | Change in data or model behavior |
| Persona Migration | User movement between personas |
| Controlled Experiment | Treatment and control comparison |
