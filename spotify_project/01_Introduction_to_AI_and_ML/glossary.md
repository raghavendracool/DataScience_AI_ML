# Important Terminology

| Term | Meaning | Spotify Example |
|---|---|---|
| Artificial Intelligence | Broad field of intelligent systems | Personalized Spotify experience |
| Machine Learning | Learning patterns from data | User segmentation |
| Deep Learning | Neural-network-based learning | Audio understanding |
| Supervised Learning | Learning with known targets | Premium conversion prediction |
| Unsupervised Learning | Pattern discovery without targets | Listener personas |
| Classification | Predicting a category | Churn or Not Churn |
| Regression | Predicting a number | Future listening minutes |
| Clustering | Grouping similar observations | Power Streamers and Casual Snackers |
| Feature | Model input | Skip rate |
| Label | Known category | Premium / Free |
| Target | Output to predict | `churn_flag` |
| Cluster | Technical group | Cluster 2 |
| Segment | Business group | Loyal users |
| Persona | Descriptive segment identity | Habitual Loyalists |
| Training Data | Data used to learn | Historical labelled user records |
| Validation Data | Data used to tune | Compare model settings |
| Testing Data | Unseen evaluation data | Final performance check |
| Churn | User leaves or reduces activity | Inactive listener |
| Retention | Keeping users active | Repeat monthly listening |
| Engagement | User interaction level | Listening time and sessions |
