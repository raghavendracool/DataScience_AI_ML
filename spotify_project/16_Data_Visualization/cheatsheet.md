# Module 16 — Quick Cheat Sheet

## Common Charts

```text
Histogram  → Distribution
Box Plot   → Spread and outliers
Bar Chart  → Category comparison
Scatter    → Relationship
Heatmap    → Matrix pattern
Pair Plot  → Pairwise exploration
Cluster    → Projected separation
Radar      → Multi-dimensional profile
Dashboard  → Monitoring
```

## Good Chart Checklist

```text
Clear question
Correct chart
Readable title
Labeled axes
Correct units
Honest scale
Low clutter
Useful context
Actionable insight
```
