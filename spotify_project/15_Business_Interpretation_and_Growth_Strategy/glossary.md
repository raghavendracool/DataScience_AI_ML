# Module 15 — Glossary

| Term | Simple Meaning | Spotify Example |
|---|---|---|
| Business Interpretation | Meaning for a decision | High ad skipping suggests friction |
| Growth Strategy | Plan to improve outcomes | Premium-conversion test |
| Personalized Recommendation | Tailored content | Persona-specific playlist |
| Premium Conversion | Free to paid movement | Premium trial |
| Retention | Continued activity | 90-day retained user |
| Churn | Inactivity or cancellation | User stops listening |
| Churn Reduction | Preventing churn | Re-engagement campaign |
| Advertisement Optimization | Balance revenue and experience | Reduce ad pressure |
| Playlist Strategy | Playlist type and format | Long-session mix |
| Discovery Strategy | Amount of new content | Controlled novelty |
| Loyalty Reward | Benefit reinforcing behavior | Artist milestone |
| Engagement | Frequency, depth, quality, consistency | Active days |
| CLV | Future customer contribution | Contribution-margin value |
| Incremental Revenue | Revenue caused by action | Treatment minus control |
| Action Prioritization | Decide what to test first | Impact vs effort |
| Impact | Expected benefit | Retention lift |
| Effort | Required resources | Engineering work |
| Confidence | Strength of evidence | 0.75 |
| Risk | Possible negative outcome | Ad fatigue |
| Primary KPI | Main success measure | Conversion rate |
| Guardrail KPI | Protects against harm | Churn rate |
| A/B Test | Treatment vs control | New vs current message |
| Counterfactual | Outcome without action | Control-group result |
| Persona Migration | Movement between personas | Casual to loyal |
