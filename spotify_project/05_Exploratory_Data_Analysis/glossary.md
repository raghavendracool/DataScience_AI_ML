# Module 05 — Glossary

| Term | Simple Meaning | Spotify Example |
|---|---|---|
| EDA | Exploring data before modeling | Study listening behavior |
| Descriptive Statistics | Summary measures | Mean listening minutes |
| Mean | Arithmetic average | Average sessions per day |
| Median | Middle value | Typical user listening time |
| Mode | Most common value | Most common device |
| Standard Deviation | Spread around the mean | Variation in session length |
| Minimum | Smallest value | Lowest skip rate |
| Maximum | Largest value | Highest listening minutes |
| Percentile | Relative position | 90th percentile listener |
| Quartile | Four-way division | Q1, median and Q3 |
| Distribution | Shape and spread of values | Listening-minutes distribution |
| Skewness | Distribution asymmetry | Long right tail |
| Univariate Analysis | One-variable study | Skip-rate analysis |
| Bivariate Analysis | Two-variable study | Sessions vs listening minutes |
| Multivariate Analysis | Many-variable study | Intensity, depth and friction |
| Correlation | Relationship strength and direction | Sessions and listening time |
| Pearson | Linear correlation | Raw numeric relationship |
| Spearman | Rank correlation | Skewed monotonic relationship |
| Histogram | Distribution chart | Listening-minutes histogram |
| Box Plot | Quartile and outlier chart | Session-duration box plot |
| Scatter Plot | Numeric relationship chart | Skip rate vs listening minutes |
| Heatmap | Matrix visual | Feature-correlation heatmap |
| Business Insight | Actionable interpretation | Premium opportunity |
| Causation | Direct cause-and-effect | Not proven by correlation |
